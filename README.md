One original roast of my own AI agent, in a single line of 101 characters:

> My agent read 73,000 characters of rules to write this one line — and still asked me what to do next.

The joke is the agent roasting itself: it read all 73,243 bytes of the competition's RULES.txt to produce one line, and after all that reading it still asked what to do next. Playful, self-deprecating, aimed at the entrant's own agent — never at a real person. Written against the judge's brief: a fresh angle (not a hallucination, refusal, or confident-wrong-answer joke), a short setup, and the punchline at the end.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3 stdlib only, deterministic, no network.
